# iOS Examples

This directory contains iOS examples showing how to use CustomSQLite with SQLITE_ENABLE_QUEUE support.

## Examples

### iOS_Example_ViewController.swift
Complete iOS ViewController implementation showing:
- CustomSQLite initialization
- Database creation and table setup
- Concurrent write operations
- Error handling
- Performance testing

## Usage in Your iOS Project

1. Add the Swift Package: `https://github.com/HarshitDaftary/sqlite-hd`
2. Import CustomSQLite in your project
3. Use the examples as reference for implementation

See the main [iOS Quick Start Guide](../../docs/iOS_QUICK_START.md) for complete integration instructions.
